# Contributing to Orchestra Agent

Thanks for considering contributing to Orchestra Agent! We welcome contributions from anyone, whether it's a bug fix, a new feature, or just a suggestion.

## Getting Started
To get started, follow these steps:
1. Clone the repository: `git clone https://github.com/orchestra-agent/orchestra-agent.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the tests: `pytest`

## Submitting a Pull Request
To submit a pull request, follow these steps:
1. Create a new branch: `git checkout -b my-branch`
2. Make your changes: `git add .`
3. Commit your changes: `git commit -m 'My changes'`
4. Push your changes: `git push origin my-branch`
5. Create a pull request: `git pull-request my-branch`

## Code Review
All pull requests will be reviewed by the maintainers. To ensure your pull request is accepted, please follow these guidelines:
1. **Test coverage**: Make sure your changes are covered by tests.
2. **Code style**: Follow the existing code style.
3. **Documentation**: Update documentation as necessary.
